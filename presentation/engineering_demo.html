The calculation, interface and checks

The service makes the evaluated procedure available to a user and to other software.

  1. Check the counts

    Require the correct targets and finite, nonnegative values.

  2. Normalize each specimen

    Use the 12 housekeeping targets to prepare the 758 model inputs.

  3. Score and flag

    Apply the saved model, then its frozen threshold.

Training calls the shared normalization function

features = normalize_counts(raw_counts)

The service and command line use Predictor.predict

normalized = normalize_counts(counts, self.schema)
return self.predict_normalized(normalized)

Normalization uses only the specimen’s counts. Learned scaling and feature selection are fitted on training data and preserved with the fitted model.

Another program sends the same CSV to POST /predict and receives a structured result.

Request · one specimen and all 770 counts

Invoke-RestMethod `
  -Uri http://127.0.0.1:8766/predict `
  -Method Post -ContentType 'text/csv' `
  -InFile no-rejection.csv
